## 🧠 Flagship Project

<div align="center">

### 🤖 Machine Health Intelligence System

<img src="https://img.shields.io/badge/Status-In_Development-7C3AED?style=for-the-badge" />&nbsp;
<img src="https://img.shields.io/badge/Type-AI_IoT_Platform-38BDF8?style=for-the-badge" />&nbsp;
<img src="https://img.shields.io/badge/Domain-Predictive_Maintenance-0c2340?style=for-the-badge" />

</div>

<br/>

> 🏭 **End-to-end industrial IoT platform** that ingests real-time sensor data from machinery and applies machine learning to **predict equipment failures before they occur** — enabling proactive maintenance and eliminating unplanned downtime.

<br/>

**System Architecture**

```
┌──────────────────────────────────────────────────────────────────────┐
│                   Machine Health Intelligence System                  │
├─────────────────┬──────────────────┬─────────────────┬──────────────┤
│   IoT Sensors   │  FastAPI Backend │   ML Pipeline   │  Dashboard   │
│  ─────────────  │  ──────────────  │  ─────────────  │  ──────────  │
│  Vibration      │  REST Ingestion  │  LSTM Detector  │  Live Charts │
│  Temperature    │  WebSocket Push  │  Anomaly Score  │  Alert Panel │
│  Pressure       │  Async Pipeline  │  ONNX Inference │  Status View │
│  RPM / Current  │  MongoDB Write   │  Health Index   │  Trend Logs  │
└─────────────────┴──────────────────┴─────────────────┴──────────────┘
```

<br/>

<table border="0" width="100%">
<tr>
<td width="50%" valign="top">

**🔬 ML Engineering**

- PyTorch LSTM for multivariate time-series anomaly detection
- Rolling-window feature extraction (mean, std, FFT components)
- SMOTE oversampling + focal loss for severe class imbalance (~1% fault rate)
- ONNX model export for sub-50ms real-time inference
- Scikit-learn ensemble baselines for benchmark comparison

</td>
<td width="50%" valign="top">

**⚙️ Systems Engineering**

- FastAPI async ingestion with WebSocket real-time push
- Configurable alert thresholds per equipment type profile
- Continuous equipment health index scored 0–100
- MongoDB time-series collections with aggregation pipelines
- Historical trend analysis with configurable prediction windows

</td>
</tr>
</table>

**Engineering Challenges**

| Challenge | Approach |
|:---|:---|
| ~1% anomaly rate → severe class imbalance | SMOTE + PyTorch focal loss weighting |
| Sub-50ms inference requirement in production | ONNX Runtime export with async FastAPI |
| Feature extraction from raw sensor streams | Rolling statistics + FFT frequency-domain |
| Alert fatigue from static thresholds | Dynamic per-equipment threshold calibration |
| Real-time data delivery to React dashboard | FastAPI WebSocket + `useEffect` event listener |

<br/>
